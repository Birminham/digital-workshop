## Product Description

PDF Magic is the PDF toolkit that never sends your files to a server. Need to merge reports? Split a scanned document? Compress a bloated PDF? Convert to images? All done locally with WebAssembly — fast, private, and free.

Stop uploading sensitive documents to random PDF sites. Your browser is powerful enough.

---

## Key Features

### 🔗 Merge PDFs
- Combine multiple PDFs into one
- Drag-and-drop file ordering
- Maintains page quality

### ✂️ Split PDFs
- Extract specific pages
- Split by page range (e.g. 1-5, 8, 10-12)
- Split every page into separate files

### 🗜️ Compress PDFs
- Optimize PDF structure (object streams)
- Remove unused objects
- Note: does not recompress embedded images (pdf-lib limitation)

### 🔄 Convert
- PDF → PNG (per-page or all pages)
- PDF → JPEG
- Adjustable resolution (1× to 4×)

### 🔒 Privacy & Security

## FAQ

**Q: Is this really free? What's the catch?**
A: No catch. The code runs in your browser using WebAssembly. There's no server cost. We don't see your files — ever.

**Q: What about sensitive documents?**
A: Perfect use case. Tax returns, contracts, medical records — they never leave your computer. Zero network requests after initial page load.

**Q: Can it handle scanned PDFs?**
A: Yes for merge/split/reorder. Compression is less effective on pure-image PDFs since they're already compressed.

**Q: Does it work offline?**
A: Yes. Once loaded, the entire toolkit works without internet.
