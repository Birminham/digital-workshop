# Screenshot Beautifier — ProductHunt Launch Page

**Tagline:** Add gorgeous frames, gradients, and shadows to your screenshots — in seconds.

## One-Liner (50 chars)
Frame your screenshots beautifully. No signup.

## Description (for ProductHunt)
Screenshot Beautifier is a free browser-based tool that turns raw screenshots into polished, share-ready images.

Drag & drop your screenshot, then choose from 5 device frames (iPhone 15 Pro, Mac Safari, Chrome Browser, Shadow Card, or no frame), 7 gradient backgrounds, and fine-tune padding, border-radius, and shadow intensity. Add a watermark and export as high-res PNG at 1x/2x/3x resolution.

Key features:
✨ 5 realistic device frames built with pure CSS
🎨 7 gradient presets + custom color picker
🔲 Adjustable padding, corner radius, shadow
💧 Custom watermark with position & opacity
📥 Export PNG at 1x/2x/3x resolution
🔒 100% browser-side — no uploads, no servers

## Why I Built This
Every time I shared a screenshot on Twitter or in a presentation, I'd spend 10 minutes in Figma adding a background and drop shadow. Now it takes 5 seconds.

## Tech Stack
React + Vite + html2canvas. Everything runs locally in the browser.

## Pricing
Free. No ads. No watermarks. No signup required.

# Image Crush — ProductHunt Launch Page

**Tagline:** Batch compress images in your browser. Free, fast, private.

## One-Liner (50 chars)
Compress, resize, convert images. Batch. Free. Private.

## Description (for ProductHunt)
Image Crush is a privacy-first batch image compressor that runs entirely in your browser. No files ever leave your computer.

Upload multiple images at once, choose your output format (JPEG, PNG, WebP, AVIF), adjust quality and scale, and watch real-time before/after comparisons slide by slide. Download individual files or grab everything as a ZIP.

Key features:
🗜️ Batch compress — drag & drop 50+ images
🔄 4 output formats — JPEG, PNG, WebP, AVIF
📊 Real-time comparison — slider to see before/after
📦 ZIP download — one click, all files
⚡ 4 concurrent workers — fast processing
🔒 Zero server upload — everything in your browser

## Why I Built This
TinyPNG limits 20 images and uploads to their server. I wanted an unlimited, private alternative that just works.

## Tech Stack
React + Vite + Canvas API + JSZip. No backend, no tracking, no limits.

## Pricing
Free. Unlimited compressions. No registration.

# PDF Magic — ProductHunt Launch Page

**Tagline:** Merge, split, compress PDFs. Free, browser-native, private.

## One-Liner (50 chars)
PDF tools that work offline. Merge, split, compress.

## Description (for ProductHunt)
PDF Magic is a set of essential PDF tools that work directly in your browser. Merge multiple PDFs into one, split a PDF by pages, and compress PDFs to reduce file size — all without uploading anything to a server.

Key features:
📎 Merge PDFs — combine unlimited files
✂️ Split PDFs — extract specific pages
📉 Compress PDFs — reduce file size significantly
🔄 Format conversion — PDF to/from common formats
🔒 Zero server upload — all processing is local

## Why I Built This
I was tired of sketchy "free PDF" sites that upload your sensitive documents to their servers. This one processes everything locally.

## Tech Stack
React + PDF-lib + Browser APIs. Fully offline-capable.

## Pricing
Free. No file limits. No accounts.
